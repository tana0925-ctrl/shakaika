# 社会科同好会 成長の道しるべ（学びのコンパス）

## Project Overview
- **Name**: 社会科同好会 成長の道しるべ
- **Goal**: 会員が自分の現在地と次のステップを選択・記録でき、管理者が全会員の状況を一覧で把握できるWebアプリ
- **Features**: 
  - 会員登録・ログイン認証
  - 5つの成長視点 x 4段階ステップの対話型ルーブリック
  - 各セルをクリックして「今の自分」を選択・メモ付きで保存
  - 管理者ダッシュボード（全会員の選択状況を一覧表示）
  - CSV(Excel対応)エクスポート機能
  - A4横印刷対応

## URLs
- **ログインページ**: `/login`
- **マイページ（会員用）**: `/mypage`
- **管理者ダッシュボード**: `/admin`
- **DB初期化**: `/api/init`（初回アクセス時に1度実行）

## API Endpoints
| Method | Path | 説明 |
|--------|------|------|
| GET | `/api/init` | DB初期化＆管理者アカウント作成 |
| POST | `/api/auth/register` | 会員登録 |
| POST | `/api/auth/login` | ログイン |
| GET | `/api/auth/me` | 現在のユーザー情報取得 |
| GET | `/api/selections` | 自分の選択状況取得 |
| POST | `/api/selections` | 選択を保存/更新 |
| DELETE | `/api/selections/:viewpoint` | 選択を削除 |
| GET | `/api/admin/members` | 全会員一覧（管理者のみ） |
| PUT | `/api/admin/members/:id/role` | 役割変更（管理者のみ） |
| DELETE | `/api/admin/members/:id` | 会員削除（管理者のみ） |
| GET | `/api/admin/export` | CSV エクスポート（管理者のみ） |

## Default Admin Account
- **Email**: admin@example.com
- **Password**: admin123

## Data Architecture
- **Database**: Cloudflare D1 (SQLite)
- **Tables**: 
  - `users` - 会員情報（名前、メール、パスワードハッシュ、役割）
  - `selections` - 各会員の選択記録（視点、ステップ、メモ）
- **Authentication**: SHA-256ハッシュ + Bearer Token

## User Guide
1. `/api/init` にアクセスしてデータベースを初期化
2. `/login` で新規登録またはログイン
3. マイページでルーブリック表のセルをクリックして「今の自分」を選択
4. メモを追加して「保存する」ボタンを押す
5. 管理者は `/admin` で全会員の選択状況を確認、CSVダウンロード可能

## みんなの気づき（2026-10-23 追加）
- 回答フォーム（会員・ゲスト共通）の最後に、任意の同意欄「名前なしで紹介してもよい／名前ありで紹介してもよい」が自動で付く（質問ではないのでCSV・質問数には入らない）。同意は share_consents（anon / named / none）。この機能より前の回答には行が無く、紹介の対象外。
- 管理者：イベント管理 → 各回の「みんなの気づき」タブで、同意した人の文章回答だけを一覧。文面を直して「採用」／取り消し。採用文は shared_insights に別保存（元の回答は書き換えない）。
- 表示：会員が受付QRで出席した画面（前回の学びカードの下）に「前回のみんなの気づき」、マイページ → /mypage/insights に研修会ごとの一覧。どちらもログインした会員のみ。名前あり同意は名前だけ（学校名なし）、名前なし同意は名前を出さない。表示のたびに今の同意を確認する。
- ゲストの受付画面には出さない（ログイン不要の画面のため、外部の人に見えてしまうおそれがある）。
- migration 0007（D1に適用済み）。

## 分析ダッシュボード・視点の読みかえ表（2026-10 追加・管理者のみ）
- 管理画面 →「分析」（/admin/analytics）：年度全体・回ごとの参加人数／回答人数／回答率、成長の視点（「選んだ人の割合」と「全選択に占める割合」を分母つきで区別）、回ごとの比較（割合）、前回の学びカードのボタン集計、自由記述の一覧と語の頻度。AIは使わない。
- 「AIに貼る用にコピー」：名前などを伏せた文章（「回答の傾向」と「運営への提案」を分けて書く指示つき）を作り、外部AIに貼る。
- 「読みかえ表」（/admin/viewpoints）：表記ゆれの選択肢を共通の視点名にまとめる対応表（viewpoint_aliases、migration 0008）。元の回答は書き換えない。コードは src/growth_common.ts・src/growth_analytics.ts。
- 初期値：「カフート」は先生の判断で「その他」にまとめている（読みかえ表で変更できる）。

## 学びの記録（個人ポートフォリオ）（2026-10 追加）
- マイページ →「わたしの学びの記録」（/mypage/portfolio）、管理者は会員一覧の芽のボタン（/admin/portfolio?uid=）。本人と管理者のみ。
- 参加した研修会、選んだ視点（読みかえ表でまとめる）・理由・試してみたいこと、前回の学びカードを時系列で。視点の回数と回ごとの変化、道しるべ（STEP）とのつながり、本人の記述からテンプレートで作る「次の目標を考えるための問い」。点数・順位・評価は出さない。コードは src/growth_portfolio.ts。

## 年度末の成長レポート・印象に残った言葉（2026-10 追加）
- 学びの記録 →「年度末の成長レポート」（/mypage/report、管理者は /admin/report?uid=）。参加履歴・視点の移り変わり・印象に残った言葉・前回の学びカード・今年度の目標／振り返り・来年度に向けた問い。印刷用レイアウトで、ブラウザの印刷から「PDFに保存」。AIによる評価文は入れない。
- 印象に残った言葉：学びの記録で自分の記述の☆を押して残す（kept_words、migration 0009）。元の回答は書き換えない。

## 重複のまとめ（2026-10 追加・管理者のみ）
- 管理画面 →「重複のまとめ」（/admin/duplicates）。同姓同名・表記ゆれの会員どうし、会員と同名のゲストを一覧。自動統合はしない。見比べて「同じ人だと確認しました」にチェックしたときだけ統合。
- ゲスト→会員：回答を会員の回答として付け替え（ゲストの元の行は統合の記録に保存）。会員どうし：重ならない記録だけ残す側へ付け替え、重なる記録と元のアカウントは残す。
- すべて merge_logs に記録し、「統合の記録」から元に戻せる。「別人として記録」で候補から外せる（duplicate_dismissals）。migration 0010。コードは src/growth_duplicates.ts。
